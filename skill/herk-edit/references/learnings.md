# herk-edit learnings

Patterns from real runs, written only on the operator's confirmed yes. SKILL.md stays untouched until a later
conformance pass promotes an entry. A note about one brand's look goes into that brand's `DESIGN.md`, not here.

## Entry format
- **Date:** YYYY-MM-DD
- **Run:** project slug, brand
- **Pattern:** what happened, in the operator's words where possible
- **Proposed change:** the rule it would become, and where
- **Status:** PENDING / PROMOTED / DROPPED
